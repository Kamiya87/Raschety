# AGENTS.md — Отчётность по продажам
## О проекте

Система подробной отчётности по продажам для руководства и финансиста. Продажи делятся на внешний отдел и внутренний, который состоит из пяти команд: Астана1, Астана2, Астана3, Шымкент и Алматы. У каждой команды свой план продаж и свои показатели по деньгам за месяц, квартал и год. Со временем в систему будут добавляться новые данные: банковские выписки по поступлениям, отчётность, которую проверяет финансист, и расчёт премий на основе этих данных. Система должна замечать аномалии и отклонения по суммам (расхождение между выпиской и отчётом, резкий скачок или провал показателя) и показывать их заметно. Файлы: index.html — разметка, styles.css — вид, script.js — логика. Требования к функциям — в папке specs/. Описание для людей — в README.md.

# Правила
Только HTML, CSS и JavaScript в этой папке. Без npm, библиотек и внешних ресурсов.
Данные храни в браузере (localStorage). Ничего не отправляй в интернет.
Интерфейс на русском языке, подписи короткие и понятные.
Кнопки и поля не меньше 44px, страница работает на телефоне шириной 375px.
Делай только то, о чём попросили. Работающие функции не ломай.
После тестов обязательно делай git commit с коротким понятным сообщением.
Суммы в тенге, с пробелом между разрядами и знаком ₸: 1 250 000 ₸. Даты в формате ДД.ММ.ГГГГ. Периоды: месяц, квартал, год.
Названия команд пиши строго так: Астана1, Астана2, Астана3, Шымкент, Алматы. Внешний отдел продаж — отдельная единица, не путай его с командами внутреннего отдела.
Банковские выписки загружаются через выбор файла в формате CSV. Читай их сам, без библиотек.
Должна быть кнопка «Выгрузить данные» и «Загрузить данные» (резервная копия в файл), чтобы данные не пропали при очистке браузера.
Аномалию (расхождение сумм, резкий скачок или провал) всегда показывай отдельным заметным пометом с объяснением, что именно не сходится. Ничего не исправляй молча.
После окончания работы делать гит коммит

# Как проверить
Открыть index.html двойным щелчком.
Ввести план и факт продаж для команды Астана1 (например, план 1 000 000 ₸, факт 800 000 ₸) → увидеть выполнение плана 80% за месяц и тот же результат в квартале и годе.
Ввести сумму, которая сильно отличается от обычной для команды → увидеть пометку об аномалии.
После F5 данные на месте.

## Git
- Коммит и push делаешь ты, но только после моей проверки и моего «да».
- Перед работой выполни git status. Есть незакоммиченные изменения — скажи и спроси, что с ними делать.
- Сделал шаг или файл требований и проверил сам — остановись. Покажи изменённые файлы (git status --short), напиши, что мне проверить руками, и спроси: «Коммитим?»
- «да» значит только коммит, а не следующий шаг. На «да» выполни по очереди: 1) git add . 2) git commit -m "<короткая подпись по-русски>" 3) git push.
-  git remote v пустой — push пропусти и скажи об этом. Push просит upstream — выполни git push -u origin <текущая ветка>. Push отклонён или просит вход — остановись и покажи ошибку целиком.
- Любая команда git не выполнилась — остановись, покажи ошибку целиком и ничего не обходи.
- Я ответил «нет» или описал ошибку — исправь, проверь снова и снова спроси. Без моего «да» не коммить.
- Историю не переписывай: без git reset --hard и git push --force.

## Большая функция

- Первым ставь шаг, на котором строятся остальные.
- Делай только один шаг за раз. Сделал — отметь его [x] в разделе «Шаги» и действуй по разделу «Git».
